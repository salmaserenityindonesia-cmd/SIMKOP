# Plan 17.2: Build Endpoints for End-of-Day, Fast-Moving Margin, and Stock Valuation

**Status:** ⬜ Not Started
**Wave:** 2

## Objective
Membangun service backend dan rute API untuk agregasi data laporan retail (Tutup Kasir, Fast-Moving, Stock Valuation).

## Action
1. Buat endpoint GET `/api/reports/retail/end-of-day`:
   - Parameter: `startDate`, `endDate`, `cashierId`.
   - Ambil dari `public.sales` yang berstatus 'completed'.
   - Lakukan relasi join ke `public.pengelola` (kasir) dan `public.anggota` (pembeli).
   - Agregasikan: total_amount, subtotal, discount, paid_cash, paid_deposit, paid_credit.
2. Buat endpoint GET `/api/reports/retail/fast-moving`:
   - Parameter: `startDate`, `endDate`, `categoryId`, `sortBy`.
   - Agregasikan `public.sale_items` join `public.products`: hitung total kuantitas terjual, total omzet (qty * unit_price), modal HPP (qty * buy_price), laba kotor, dan persentase margin.
3. Buat endpoint GET `/api/reports/retail/stock-valuation`:
   - Parameter: `categoryId`, `stockStatus` (all/low/out).
   - Hitung total valuasi aset (SUM(stock * buy_price)), potensi nilai jual (SUM(stock * sell_price)), dan filter produk stock <= min_stock_alert.

## Target Files
- `src/services/retail-report.service.ts`
- `src/controllers/retail-report.controller.ts`
- `src/routes/report.routes.ts`

## Verification
- Uji ketiga endpoint (misal: via unit test atau integrasi UI): verifikasi pemisahan pembayaran tunai/deposit/bon, kalkulasi margin laba, dan perhitungan valuasi aset akurat.
