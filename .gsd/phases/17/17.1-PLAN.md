# Plan 17.1: Generate Retail & Inventory Reports Dashboard with Stitch MCP

**Status:** ⬜ Not Started
**Wave:** 1

## Objective
Menghasilkan antarmuka "Laporan Retail & Inventori Toko SIMKOP" menggunakan Stitch MCP, dengan standar Tailwind CSS dan layout dashboard.

## Action
Panggil tool Stitch MCP yang terhubung untuk menghasilkan antarmuka:
- Breadcrumb: SIMKOP / Laporan / Laporan Retail & Inventori
- Top Toolbar: Date Range Picker, Filter Kategori / Kasir, Tombol "Export Excel" & "Cetak PDF".
- Tab Switcher:
  * Tab 1: [Tutup Kasir Harian]
  * Tab 2: [Produk Terlaris & Margin]
  * Tab 3: [Status Stok & Valuasi]
- Tab 1 Layout:
  * 4 Metric Cards: Total Omzet, Uang Tunai Kasir (paid_cash), Potong Simpanan (paid_deposit), Bon Toko (paid_credit).
  * Tabel Log Transaksi Penjualan lengkap dengan info kasir dan nama anggota.
- Tab 2 Layout:
  * Top 3 Fast-Moving Items Showcase Cards.
  * Tabel Ranking Produk Terlaris dengan rincian Omzet, HPP modal, Laba Kotor, dan Progress Bar Margin Laba.
- Tab 3 Layout:
  * 3 Metric Cards: Valuasi Aset Toko (Beli), Potensi Omzet (Jual), Jumlah Item Butuh Restock.
  * Tabel Inventori Produk dengan Badge Indikator Kritis dan perhitungan aset per baris.

## Target Files
- `src/pages/admin/laporan-retail/index.tsx`
- `src/components/reports/retail/*`

## Verification
- Pastikan antarmuka ter-generate rapi dengan Tailwind CSS dan tidak ada error TypeScript.
