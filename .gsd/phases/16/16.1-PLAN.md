# Plan 16.1: Generate Financial Reports Dashboard UI via Stitch MCP

## Objective
Generate antarmuka "Dashboard Laporan Keuangan Terpadu SIMKOP" menggunakan Stitch MCP, lalu port hasilnya ke `src/pages/admin/laporan-keuangan/index.tsx`. UI ini mencakup dua tab: Arus Kas (Cash Flow) dan Estimasi SHU Berjalan.

## Context Files
- `src/components/layout/AdminLayout.tsx` — layout shell & design tokens reference
- `src/index.css` — design system tokens
- `src/pages/admin/ManajemenAnggota.tsx` — referensi pola halaman admin

## Tasks

### Task 1: Generate UI via Stitch MCP
Call Stitch MCP `generate_screen_from_text` with prompt describing:
- Breadcrumb: SIMKOP / Laporan / Laporan Keuangan Terpadu
- Top Toolbar: Start Date, End Date, Quick Presets (Hari Ini, Bulan Ini, Tahun 2026), Filter Unit Usaha (dropdown), Export Excel button, Download PDF button
- Tab Switcher: [Arus Kas (Cash Flow)] | [Estimasi SHU Berjalan]
- Tab 1 — Arus Kas:
  * 3 metric cards: Total Kas Masuk (emerald), Total Kas Keluar (rose), Saldo Kas Bersih (slate/blue)
  * Table: tanggal, deskripsi, kategori, kas masuk, kas keluar, saldo berjalan
- Tab 2 — Estimasi SHU:
  * 5 waterfall cards: Omzet Penjualan, HPP, Laba Kotor, Beban Operasional, Estimasi SHU Bersih
  * Widget alokasi RAT: Cadangan Modal (40%) dan Bagian Anggota (60%)
