# Plan 4.2: Pengajuan Pinjaman Baru

## Objective
Membuat antarmuka dan layanan untuk mengajukan pinjaman tanpa bunga. Ini adalah form sederhana untuk menginput jumlah pinjaman dan tenor cicilan.

## Context
- .gsd/SPEC.md
- src/services/koperasiService.ts
- src/pages/admin/DashboardSimpanan.tsx

## Tasks

<task type="auto">
  <name>Pinjaman Types and Service Methods</name>
  <files>src/services/koperasiService.ts</files>
  <action>
    - Tambahkan tipe `Pinjaman` (id, anggota_id, jumlah, tenor_bulan, status, created_at). Status default "pending".
    - Buat fungsi `ajukanPinjaman(data)` untuk melakukan insert ke tabel pinjaman (berikan fallback mock dummy id jika error schema).
  </action>
  <verify>npm run build</verify>
  <done>Fungsi ajukanPinjaman tersedia di service.</done>
</task>

<task type="auto">
  <name>Build Form Pengajuan Pinjaman</name>
  <files>src/components/admin/FormPengajuanPinjaman.tsx, src/pages/admin/DashboardSimpanan.tsx</files>
  <action>
    - Buat modal komponen `FormPengajuanPinjaman` berisi form input: Jumlah Pinjaman (angka) dan Tenor (select: 3, 6, 12 bulan).
    - Karena pinjaman 0% bunga, pastikan UI dengan jelas menyebutkan bahwa Cicilan per bulan = Jumlah / Tenor.
    - Tambahkan tombol "Ajukan Pinjaman" pada baris tabel anggota di `DashboardSimpanan.tsx` yang akan memunculkan modal ini.
    - Hubungkan dengan fungsi `ajukanPinjaman` pada submit.
  </action>
  <verify>npm run build</verify>
  <done>Form modal pengajuan pinjaman dapat dibuka dan data pengajuan dapat disubmit ke service.</done>
</task>

## Success Criteria
- [ ] Tipe Pinjaman terdefinisi.
- [ ] Form input pinjaman 0% bunga tersedia dan menghitung cicilan pokok / tenor secara UI.
- [ ] Submisi form terhubung dengan service.
