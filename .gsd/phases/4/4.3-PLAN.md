# Plan 4.3: Approval Workflow

## Objective
Menyediakan mekanisme bagi role Admin untuk menyetujui atau menolak pengajuan pinjaman yang berstatus pending.

## Context
- .gsd/SPEC.md
- src/services/koperasiService.ts
- src/pages/admin/ApprovalPinjaman.tsx (New)

## Tasks

<task type="auto">
  <name>Approval Service Methods</name>
  <files>src/services/koperasiService.ts</files>

  </action>
  <verify>npm run build</verify>

- [ ] Daftar pinjaman "pending" dapat dilihat.
- [ ] Tombol Setujui dan Tolak berfungsi untuk memanggil service update.
- [ ] Validasi role (hanya admin) diimplementasikan secara UI (sembunyikan tombol atau beri alert).
